# PawConnect Agent Skills

Canonical task skills live here.

- `pawconnect-product` — scope, roles, workflows, product priorities
- `pawconnect-uiux` — visual design, IA, navigation, landing page, dashboards, anti-AI-slop rules
- `pawconnect-frontend` — Next.js/React/TypeScript implementation
- `pawconnect-backend` — Server Actions, Supabase, data/domain logic
- `pawconnect-security` — Clerk, RBAC, RLS, IDOR, storage, secrets
- `pawconnect-qa` — functional, visual, responsive, security regression testing
- `pawconnect-workflow` — how an agent plans, edits, verifies, and commits

`GEMINI.md`, `CLAUDE.md`, and `AGENTS.md` at the project root point agents to this skill layer.
